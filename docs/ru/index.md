# Django Educa - Современная Образовательная Платформа

## Обзор проекта

Django Educa представляет собой современную образовательную платформу, построенную на основе Django 5 и Python 3.12. Платформа предоставляет комплексное решение для онлайн-обучения с расширенными возможностями управления контентом и взаимодействия между пользователями.

## Ключевые особенности

### Архитектурные решения
- Монолит с выделенными инфраструктурными сервисами
- Асинхронное взаимодействие через Celery и RabbitMQ
- Многоуровневое кэширование с использованием Redis
- Отказоустойчивое хранение данных в PostgreSQL

### Технический стек
- **Бэкенд**: Django 5, Python 3.12
- **Хранение данных**: PostgreSQL, Redis, MinIO (S3-совместимое хранилище)
- **Проксирование запросов**: Nginx
- **Очереди и воркеры**: Celery, RabbitMQ
- **Мониторинг**: Prometheus, Grafana
- **Логирование**: ELK Stack (Elasticsearch, Logstash, Kibana)
- **Безопасность**: Vault (управление секретами)

### Функциональность
- Система управления курсами (CMS)
- Поддержка различных типов контента (текст, видео, файлы)
- Интерактивный чат на WebSocket
- OAuth2 аутентификация (Google, GitHub)
- REST API с автоматической документацией

## Минимальные требования

- Docker и Docker Compose
- 4GB RAM
- 40GB свободного места на диске
- Процессор с поддержкой виртуализации

## Архитектура
Платформа построена на основе современных архитектурных паттернов:


- Многослойная архитектура: разделение на слои представления, бизнес-логики и данных
- Событийно-ориентированная архитектура: асинхронная обработка событий через Celery
- Монолит с контейнеризированной инфраструктурой: основное приложение — это монолит на Django, окружённый отдельными сервисами (PostgreSQL, Redis, MinIO, Vault и др.), развёрнутыми в отдельных Docker-контейнерах
- API-first design: полностью документированный REST API

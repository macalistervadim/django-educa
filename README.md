## Django Educa 🎓

<img src="https://img.shields.io/badge/Python-3.12-blue.svg" alt="Python"></img> <img src="https://img.shields.io/badge/Django-5.0-green.svg" alt="Django"></img> <img src="https://img.shields.io/badge/license-MIT-blue.svg" alt="License"></img> <img src="https://img.shields.io/github/stars/macalistervadim/django-educa.svg" alt="GitHub Stars"></img>



**Django Educa** is an educational platform built with Django. It allows you to create courses, modules, and content for learning. The project includes models for managing courses, modules, text, video, and file content.

### Documentation 📚

For more details about the project, its features, and how to use it, visit the [Django Educa Documentation](https://macalistervadim.github.io/django-educa/).
